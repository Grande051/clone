# TRABALHO PRÁTICO — DESENVOLVIMENTO DE SITE EM GRUPO

## 📌 Objetivo do trabalho

O trabalho terá como objetivo desenvolver, em grupo, um **site completo sobre um tema escolhido pelos próprios integrantes**.

Cada grupo deverá escolher um tema, planejar a estrutura do site, desenvolver as páginas e, ao final, apresentar o projeto para a turma.

O foco da atividade não será apenas entregar um site funcionando. Cada integrante deverá **entender o código desenvolvido**, saber explicar as decisões tomadas pelo grupo e demonstrar domínio sobre o próprio projeto durante a apresentação e o **Code Review**.

---

## 📅 Data de entrega

**15/09/2026**

O projeto deverá estar concluído e pronto para apresentação nesta data.

---

# ETAPAS DO TRABALHO

## 1. Escolha do tema

Cada grupo deverá escolher um tema para o desenvolvimento do site.

O tema é livre, desde que permita a criação de um site com conteúdo suficiente para demonstrar os conhecimentos trabalhados durante as aulas.

Alguns exemplos de temas possíveis:

- Tecnologia;
- Games;
- Filmes e séries;
- Música;
- Esportes;
- Turismo;
- Gastronomia;
- Educação;
- Saúde;
- Eventos;
- Empresa fictícia;
- Loja fictícia;
- Portfólio;
- Outro tema definido pelo grupo.

A escolha do tema é apenas o ponto de partida. O mais importante será a qualidade da implementação, organização e compreensão do código.

---

## 2. Desenvolvimento do site

Após a escolha do tema, o grupo deverá desenvolver o site utilizando os conhecimentos trabalhados durante as aulas.

Todos os integrantes devem participar do desenvolvimento.

O grupo deve se preocupar com:

- Organização do projeto;
- Estrutura das páginas;
- Uso correto de HTML;
- Estilização com CSS;
- Interações e comportamentos implementados com JavaScript, quando aplicável;
- Navegação entre as páginas;
- Clareza e organização do código;
- Experiência do usuário;
- Funcionamento correto do site.

O projeto deve ser desenvolvido pelo próprio grupo.

---

# ⚠️ REGRA SOBRE USO DE INTELIGÊNCIA ARTIFICIAL

## É PROIBIDO UTILIZAR INTELIGÊNCIA ARTIFICIAL PARA ESCREVER O CÓDIGO DO TRABALHO.

Isso inclui utilizar ferramentas de IA para:

- Gerar arquivos HTML;
- Gerar CSS;
- Gerar JavaScript;
- Criar funções prontas;
- Completar trechos de código;
- Reescrever código do projeto;
- Gerar páginas inteiras;
- Resolver o trabalho através de prompts;
- Copiar código produzido por ChatGPT, Copilot, Gemini, Claude ou qualquer ferramenta semelhante.

### Penalidade

> **Caso seja identificado código produzido por Inteligência Artificial, a nota do trabalho será ZERO.**

Sem exceções.

O objetivo desta atividade é avaliar a capacidade do aluno de **desenvolver, compreender e explicar o próprio código**.

Durante o Code Review, qualquer integrante poderá ser questionado sobre qualquer parte do projeto. Portanto, copiar um código que o grupo não entende ficará bastante evidente. O código pode até tentar se esconder — no Code Review ele acaba confessando.

---

# 3. APRESENTAÇÃO DO PROJETO

Após a conclusão do desenvolvimento, cada grupo deverá apresentar seu site para a turma.

Durante a apresentação, o grupo deverá mostrar:

1. O tema escolhido;
2. A proposta do site;
3. As páginas desenvolvidas;
4. A navegação entre as páginas;
5. As principais funcionalidades;
6. As decisões de layout e organização;
7. O resultado final funcionando no navegador.

Todos os integrantes deverão participar da apresentação.

---

# 4. CODE REVIEW

Após a apresentação do site, será realizado um **Code Review do projeto**.

O objetivo do Code Review é verificar se os integrantes realmente compreendem o código que desenvolveram.

Durante essa etapa, poderão ser solicitadas explicações sobre qualquer trecho do projeto.

Os alunos deverão estar preparados para explicar, por exemplo:

- Como o HTML foi estruturado;
- Para que servem determinadas tags;
- Como os elementos foram organizados;
- Como o CSS foi aplicado;
- Como funcionam classes e IDs utilizados no projeto;
- Como determinados layouts foram construídos;
- Como funcionam as partes desenvolvidas em JavaScript;
- Como funcionam condições, repetições, funções ou eventos presentes no código;
- Por que determinada solução foi escolhida;
- O que aconteceria se determinado trecho fosse alterado;
- Qual integrante participou de determinada implementação.

Também poderão ser solicitadas **pequenas alterações no código durante o Code Review** para verificar a compreensão dos integrantes.

### Importante

Não basta que apenas uma pessoa do grupo saiba explicar o projeto.

**Todos os integrantes são responsáveis pelo código entregue.**
